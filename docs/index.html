1. Your master resume

Paste your full resume once, with everything you have done. It is saved only in this browser, never sent anywhere. Each time you tailor, it picks and orders your own bullets for the job and never adds anything new.

Format: name, then a contact line, then sections that start with # (SUMMARY, SKILLS, EXPERIENCE, EDUCATION, CERTIFICATIONS). Bullets start with a dash.

2. The job

Paste any job description. This scores it with the same rules as the list: flexibility and fit signals add points, on call and crisis style language subtracts them. It runs in your browser and nothing is sent anywhere.

Connect to GitHub

Needed so changes here can update the search. Create a fine grained token at github.com/settings/personal-access-tokens/new. Limit it to this one repository, with Contents and Actions both set to Read and write. It is saved only in this browser.
